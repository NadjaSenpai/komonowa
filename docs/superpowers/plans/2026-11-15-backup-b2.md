# B2 Backup Implementation Plan

**Goal:** 合意した月4回・24世代の暗号化バックアップを自動化する。

**Architecture:** 既存D1/R2エクスポートを再利用し、GPGで暗号化してAWS CLIのS3互換APIでB2に保存する。

**Tech Stack:** Node.js、SQLite CLI、GPG、AWS CLI、GitHub Actions。

**Spec:** `docs/superpowers/specs/2026-11-15-backup-b2-design.md`

## Global Constraints

- 1・8・15・22日 JST 09:23、24世代、非公開B2、送信前暗号化。
- Secretsや平文バックアップをコミット・ログ・Actions Artifactに含めない。
- 本番の復元・デプロイ・初回バックアップはこの実装検証では実行しない。

## Review Focus

- 誤った鍵・破損した暗号文では復号が失敗すること。
- 他のキーを削除せず、バージョンIDなしでは削除しないこと。
- アップロード・取得・検証失敗時には旧世代を削除しないこと。
- SQLと添付一覧が同じ時点であること。R2取得失敗時は完了しないこと。
- Secret不足時はバックアップ取得前に失敗すること。
