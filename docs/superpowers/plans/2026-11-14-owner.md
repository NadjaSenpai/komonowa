# 所有者 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 最初の管理者を所有者にし、ほかの管理者が所有者の権限変更・無効化をできないようにする。

**Architecture:** `users.is_owner` 列とユニークな部分インデックス。API で所有者への PATCH を 403 にし、管理画面は `is_owner` を見て操作を隠す。

**Tech Stack:** D1 migration, Hono, React, vitest

**Spec:** docs/superpowers/specs/2026-11-14-owner-design.md

## Global Constraints

- エラー文：「所有者の権限変更や無効化はできません」（403）
- 適用済みのマイグレーションは編集しない。新しく `migrations/0005_owner.sql`
- `npm run check` を通してからコミット

## Review Focus

- 所有者への PATCH が、役割だけ・状態だけ・両方のどれでも 403 になること
- `{ role: "admin", status: "active" }` のような変化のない PATCH も、所有者には 403（意図をはっきりさせる）
- マイグレーションが利用者 0 人でも失敗しないこと（テストは毎回 0 人の DB に適用している）
- 所有者が2人にならないこと（インデックス）

---

### Task 1: マイグレーションと API

**Files:** Create `migrations/0005_owner.sql`; Modify `worker/routes/auth.ts`（setup）、`worker/routes/admin.ts`（GET/PATCH users）、`test/auth.test.ts`

**Interfaces:** Produces `GET /api/admin/users` の各行に `is_owner: 0 | 1`

- [ ] **Step 1: テスト**：「最後の管理者は降格・無効化できない」を「所有者はほかの管理者から降格・無効化されない」に書き換える。2人目の管理者から所有者へ `{ role: "member" }`、`{ status: "disabled" }` がどちらも 403 と上記の文言。所有者から2人目へ `{ role: "member" }` が 200。2人目の自分の降格は 400。一覧で所有者の `is_owner` が 1、2人目が 0。別テスト：所有者を2人にしようとする `UPDATE users SET is_owner = 1` が UNIQUE で失敗。
- [ ] **Step 2: 失敗を確認**：`npx vitest run --project worker test/auth.test.ts` → FAIL
- [ ] **Step 3: 実装**：マイグレーション（列、最古の管理者を 1、`CREATE UNIQUE INDEX users_owner ON users(is_owner) WHERE is_owner = 1`）、setup の INSERT に `is_owner = 1`、GET に `is_owner`、PATCH に所有者チェック
- [ ] **Step 4: 通過を確認**
- [ ] **Step 5: コミット** `feat(api): make the first admin the owner and protect them from other admins`
