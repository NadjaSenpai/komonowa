# 編集画面のマークアップツールバー 設計

## 目的

Markdown に慣れていないメンバーが、本文の上のボタンから見出し・太字・箇条書きなどの記号を入れられるようにする。記号は隠さず、そのまま本文に入れる。使っているうちに記号そのものを覚えてもらうのが狙い（見たまま編集〈WYSIWYG〉にはしない）。

## 範囲

- やる：記事の編集画面（新規・編集）の本文欄に付けるツールバー
- やらない：見たまま編集、記法の早見表ページ、既存の画像・ファイル挿入の作り直し
- 避けたいこと：ボタンで入れたものを Ctrl+Z で取り消せないこと。慣れていない人ほど「押してみて、違ったら戻す」ので、戻せないと怖くて使われなくなる

## 方式

| 案 | 内容 | 判断 |
|---|---|---|
| 1. ブラウザの文字入力として差し込む | `document.execCommand("insertText")` で入れる。ブラウザ標準の取り消し・やり直しがそのまま効く | **採用**。小さく作れ、ライブラリも不要。非推奨 API だが主要ブラウザで動き、代わりになる標準 API がない。動かないときは `setRangeText` 相当の書き換えに切り替える（その場合だけ取り消せない） |
| 2. 自前の取り消し履歴 | 本文の変化を積み、Ctrl+Z を自分で処理する | 不採用。普通の入力との境目を全部自分で決めることになり、壊れやすく、手間も大きい |
| 3. コードエディタ（CodeMirror など）に置き換える | 取り消しもショートカットも揃う | 不採用。貼り付けとドラッグ＆ドロップでの画像挿入を作り直すことになり、見た目もプログラマー向けになって目的からずれる |

## 設計（ボクの提案）

### ボタン

左から順に。ラベルは短い日本語にする。マウスを乗せたとき（`title`）と読み上げ（`aria-label`）では、**入る記号も見せる**（例：「太字　**文字**　Ctrl+B」）。覚えてもらうための大事な部分。

| ボタン | 入るもの | 選択なし | 選択あり |
|---|---|---|---|
| 見出し | 行頭に `## ` | 今の行 | 選択した各行 |
| 太字 | `**…**` | `**太字**` を入れ、「太字」を選択状態にする | 選択を囲む |
| 取り消し線 | `~~…~~` | `~~取り消し~~`（同上） | 選択を囲む |
| リンク | `[文字](https://)` | `[リンクの文字](https://)` を入れ、URL 部分を選択 | `[選択](https://)` にして URL 部分を選択 |
| ページ | `[[…]]` | `[[ページ名]]` を入れ、「ページ名」を選択 | 選択を囲む |
| 箇条書き | 行頭に `- ` | 今の行 | 選択した各行 |
| 番号 | 行頭に `1. ` `2. ` … | 今の行 | 選択した各行に連番 |
| チェック | 行頭に `- [ ] ` | 今の行 | 選択した各行 |
| 引用 | 行頭に `> ` | 今の行 | 選択した各行 |
| コード | `` `…` ``、複数行なら ```` ``` ```` で囲む | `` `コード` ``（「コード」を選択） | 1行内なら `` ` `` で、複数行にまたがれば前後の行に ```` ``` ```` を置く |

- 斜体は入れない（和文の斜体は読みにくく、使われにくい）
- すでに記号が付いているときに外す（トグル）動作は作らない。間違えたら Ctrl+Z で戻す
- ショートカット：Ctrl+B（Mac は ⌘B）で太字、Ctrl+K（⌘K）でリンク

### 置き場所と見た目

既存の「Markdown／プレビュー」タブと「画像・ファイルを挿入」ボタンの行の下に、1行で並べる。狭い画面では横にスクロールさせ、折り返さない。プレビュータブのときは押せないようにする。

```
[Markdown][プレビュー]                 [画像・ファイルを挿入]
[見出し][太字][取り消し線][リンク][ページ] | [箇条書き][番号][チェック][引用][コード]
┌──────────────────────────────────────────────┐
│ 本文                                           │
```

### 作り

- 記号の付け方は、本文と選択範囲を受け取り「どこをどう置き換え、置き換えた後にどこを選択するか」を返す純粋な関数にまとめる（`src/markup.ts` など）。テストはこの関数に書く
- 実際の差し込みは、本文欄で置き換え範囲を選択し、`execCommand("insertText")` で入れ、最後に選択範囲を戻す。入力イベントが出るので、React の state はいつもの `onChange` で更新される。`execCommand` が `false` を返したら、state を直接書き換える
- 押したあとは本文欄にフォーカスを戻す

## 実装する人に任せること

- ボタンの区切り（どこに仕切り線を入れるか）とアイコンの有無。既存のボタンの見た目に合わせる
- 関数とコンポーネントのファイル分け
