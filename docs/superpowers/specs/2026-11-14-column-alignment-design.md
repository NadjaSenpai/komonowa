# 縦の線（左端）をそろえる 設計

## 目的

画面のあちこちで左端の位置がずれていて、ページを移るたびにタイトルや本文の左端が動く。これをそろえる。

## 決まったこと

1. **上のバーと本文**：上のバーの左右の余白を本文と同じ計算（`max(24px, (100% - 1100px) / 2 + 24px)`）にする。広い画面でロゴと本文の左端がずれていた（本文だけ 24px 右）
2. **画面ごとの左端**：全画面の左端をロゴの線にそろえる。記事の表示画面は幅 760px のまま、中央寄せをやめて左寄せにする（広い画面では右が空く）。一覧と編集画面の幅は今のまま
   - 不採用：全画面を 760px の中央寄せ（一覧のタグ欄と編集画面の本文欄が窮屈になる）
3. **記事の中のリスト**：箇条書きの点・番号・☐ を同じ縦の線に、項目の文字を同じ位置にそろえる。リストの字下げを `1.75em` に固定し、☐ はその字下げの中で点や番号と同じく文字の直前（右寄せ）に置く

## やらないこと

色や文字の大きさなど、位置以外の見た目の変更。

## 確かめ方

CSS だけの変更で、テストでは確かめられない。`npm run check` が通ること、デプロイ後に画面で見てもらうことで確かめる。
