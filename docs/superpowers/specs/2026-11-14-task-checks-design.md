# チェックリストの付け外し（ブラウザに保存）設計

## 目的

チームの買い出しリストや ToDo を記事に `- [ ]` で書き、表示画面でクリックして ☐／☑ を付け外しできるようにする。チェックは記事には保存せず、そのブラウザの localStorage にだけ覚える。リロードしても残り、買い物の途中で画面を開き直しても進み具合が分かる。

## 範囲

- やる：記事の表示画面での付け外し、localStorage への保存、「チェックをすべて外す」
- やらない：記事本文への保存、ほかの人や端末との共有（必要になったら、本文に保存する別案で検討する）、プレビュー・履歴画面での付け外し
- 避けたいこと：保存されたと誤解されること、本文の編集で項目の順番が変わったときに違う項目へチェックが付くこと

## 方式

| 案 | 判断 |
|---|---|
| 本文を書き換えて保存する（専用 API で n 番目を切り替え） | 不採用。共有はできるが、利用者が「画面の上だけでよい」とした |
| 画面上だけで切り替える（リロードで消える） | localStorage 案に発展 |
| **localStorage に記事ごと・項目の文字ごとに覚える** | **採用**。リロードしても残る。共有はされないことを利用者が了承済み |

## 設計

- 描画は今のまま（`☐`／`☑` の `span.task-box`）。表示画面だけが描画後にこれを操作できる形にする：`role="checkbox"`、`aria-checked`、`tabindex="0"`、`title="このブラウザにだけ保存されます"`
- 操作：クリック、またはフォーカスしてスペース／Enter で切り替える
- 付いた項目は `li` に `done` クラスを付け、薄く取り消し線を引く
- 覚え方：キー `komonowa:task-checks:<記事ID>` に、項目キー → `true`／`false` の JSON を保存する。項目キーは「項目の文字（印を除き前後の空白を除いたもの）」＋同じ文字の何番目か（`牛乳#0`）。覚えていない項目は本文どおり（`[x]` なら付いた状態）
- 本文から消えた項目の記録は使われないだけで、消さない
- チェックがひとつでも付いていれば、本文の下に「チェックをすべて外す」を出す。押すと全項目を `false` として覚える
- localStorage が読めない・書けない（プライベートブラウズなど）ときは、画面上だけで切り替わる。エラーは出さない
- 描画し直されたとき（記事を読み込み直したとき）は、覚えている状態を当て直す

## 実装する人に任せること

- 「チェックをすべて外す」の見た目（既存の `button.link small` を想定）
- 取り消し線の色の細かい調整
