# チーム向けナレッジベース

Cloudflare Workers 上で動作する、日本語のメンバー限定 Wiki を構築する。React と Vite で UI、Hono で API を提供し、D1 に記事・認証情報・履歴、R2 に添付を保存する。Cloudflare Access の利用者枠に依存しない。

管理者による期限付き招待リンクで登録し、メールアドレスとパスワードでログインする。管理者は期限付きパスワード再設定リンクを発行し、メンバーを無効化できる。初期管理者は安全な初期化手順で作成する。

メンバーは Markdown とプレビューで記事を作成・編集し、検索、複数タグによる AND 絞り込み、削除ができる。変更履歴と復元を用意し、同時編集時は競合を検知する。削除済み記事の復元・完全削除とタグの改名・削除は管理者が行う。退会後も記事と履歴を残す。

画像、PDF、一般的な文書を最大 10 MB 添付できる。R2 を公開せず、認証済みリクエストで配信する。D1 と R2 の手動バックアップ・復元手順を用意する。コードの実装、検証、GitHub push までを対象とし、本番デプロイは含めない。
